## 效果边界

相同输入、相同依赖、相同模型/提供方和配置是比较前提。本次验证覆盖规则、输入、确定性生成与 mock 流程；真实模型存在随机性，不能据此承诺每次生成像素完全一致。GPU 可选后端、Docker 和真实模型调用需在目标环境单独验收。

原始样例视频不公开；缺失这些视频时专属回归会跳过。默认公开运行链路保留导演卡示例与统计，不因缺少原始归档而减少提示词示例。

## 版本与历史隔离

公开仓库采用独立历史，不包含原始资料提交。旧版本独立保存为私密归档。继续开发应克隆当前公开仓库，避免向公开仓库推送旧来源归档或旧历史。
