# 成本模型

## 记账

每次模型调用（包括 mock 与 dry-run）都写入台账 `usage` 表：任务、批次、步骤、提供方、模型、请求 ID、输入/缓存/输出 token、
图片数、视频秒数、金额（USD）、是否 dry-run。金额由 `configs/pricing.yaml` 计算；单价未知的调用金额记为空并单独计数，
报表会提示补全单价，而不是按 0 计入。

```powershell
wbs cost report                    # Markdown：实际金额、单价未知次数、dry-run 预估，按模型/任务
wbs cost report --batch B20260927 --format csv
```

## 单价（configs/pricing.yaml）

所有单价以美元计，是从源文档成本记录反推的示例，正式生产前按合同价格更新：

| 模型 | 计价 | 来源 |
|---|---|---|
| mock | 0 | — |
| gpt-6-astra | 输入 $10 / 缓存输入 $1 / 输出 $50 每百万 token | [D7] 成本表反推（普通输入 14.7 万≈$1.47、缓存 196.6 万≈$1.97、输出 1.03 万≈$0.51） |
| skill-agent-default | 输入 $3 每百万 token（输出未给出） | [D2]：“按 $3/百万 input 这档定价，新开对话做一条视频大约 $0.5–1.5（约 4–11 元）” |
| doubao-seedance-2.5 | $0.682 每视频秒 | [D7] 后台截图：30 秒成片约 $20.46（文档记约 140 元） |
| gpt-image | 未给出（null） | 需按实际网关价格补全 |

汇率 `usd_to_cny: 7.0`（[D7]“按 1 美元≈7 元粗算”），按需调整。

## 预算与确认

- `configs/default.yaml`：`cost.budget.per_job_cny`（默认 ¥50）与 `per_batch_cny`（默认 ¥2000）。每次真实调用前按
  “已花 + 本次预估”检查，超出即拒绝（`BudgetExceeded`）。
- 真实调用必须显式确认：`--confirm-paid` 或 `WBS_CONFIRM_PAID=1`；否则报错并提示先 dry-run。
- `--dry-run`：真实提供方不会被调用，按请求估算 token 记一条 dry-run 记录，然后用 mock 输出继续，便于先看清调用清单和费用。

## 估算参考

- 反推（agent 方式，[D2]）：约 ¥4–11 / 条。本平台的规则分析与求解在本地运行、零模型费用；只有可选的视觉标注与修正代理会调用模型。
- V2V：每条约 1 次规划调用（含总览与关键帧图片）+ 每图 1 次生图 + 视频生成按秒计费（Seedance 2.5 约 $0.682/秒，
  15 秒约 $10.2≈¥72，30 秒约 $20.5≈¥143）。生图单价未知，报表会单独列出“单价未知”的次数。
