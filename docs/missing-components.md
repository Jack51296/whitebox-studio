# 运行资源与效果边界

- Python ≥ 3.11，Blender 5.1.2，FFmpeg / ffprobe；工具下载见 `scripts/fetch_tools.ps1`。
- 模型提供方默认 mock。真实 LLM、生图、V2V 需要自选提供方、模型版本、凭证和预算确认。
- 中精度人物需要自行提供已授权 FBX 资产并配置 `fbx_library`；默认低精度几何代理。
- 可选视觉模型默认关闭，缺失自动回退。门控模型需使用者自行申请授权。
- 公开运行数据保留基线 21 份导演卡的程序字段。原始视频、图片和生产报告不随发布分发；它们不是运行库必需资源。
- Docker、GPU 视觉后端、真实模型效果需在目标设备单独验证；本次回归不代表这些环境已测试。

缺失资源应记录为 `not_run` 或明确回退，不改阈值、不编造检查结果。
