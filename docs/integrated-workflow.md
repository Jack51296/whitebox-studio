# 完整运行流程

## 1. 规格与规则

默认规格由 `configs/default.yaml` 给出。结构抽样由 `taxonomy/` 定义，提示词由 `prompts/` 按 id 和版本调用。

## 2. 正向规划

结构树批量、故事分层链、长镜头规划都生成 `scene.json`。故事链按前提→人物→事件→空间→分镜运行；使用 21 份脱敏导演卡中的固定 4 份示例。评审→修正最多 2 轮，逐层格式错误最多重试 3 次。路线与机位由编译器转换为关键帧。

## 3. 反向求解

授权视频→抽帧、切镜、光流、占幅和结构线→场景草稿→静态闸门与修正。可选视觉后端缺失时自动回退，并记录实际使用后端。

## 4. 白模渲染与检查

运动上限、穿模、遮挡构图、镜头语法、节奏和铺垫可读性→Blender 逐帧建场→H.264 无声视频→媒体、剪辑、景别、速度、朝向、构建一致性与多样性报告。阈值见 `docs/qc-gates.md` 和默认配置。人工抽检、正常速度观看和采用状态不能由程序代填。

## 5. V2V 三节点

同版白模视频、分镜总览、导演卡和续作提示词→Skill v3 规划→取帧与生图→绑定打包→默认导出提交说明。系统提示词与契约直接读取 `skills/generate-whitebox-v2v-package/references/`，正文与验证基线一致。

## 6. 交付与续跑

SQLite 状态台账、输入哈希幂等续跑、费用台账与预算闸门、批次 ZIP、模型导出和双路对比看板。模型调用默认 mock；真实调用需明确确认，不以 mock 结果描述真实效果。

命令和目录见 `runbook.md`；数据字段见 `data-contracts.md`；发布验证见 `public-release.md`。
