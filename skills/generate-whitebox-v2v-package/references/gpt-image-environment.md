# GPT 生图：真实环境与合理细节补充

用户已指定生图使用 GPT；视频仍按已指定的 SD2.5。这里只规定图片提示词写法，具体 GPT 生图模型 ID、接口和参数沿用用户实际配置，不猜版本、不自动换模型。

本规则适用于全景文生图与局部图生图。真实感包含两部分：物体本身的结构、材质与光照，以及地点中合理存在的环境内容。后者需要主动设计，不能因为白模省略了路人、植被和日常设施，就把成片环境也写得空旷。

## 生图的最高优先级：白模提供逻辑，真实场景重新设计

把白模帧读成“哪些区域相连、谁在前后或上下、通道如何通过、障碍在哪里、斜度和高差如何使动作成立”的关系说明。以这些必要关系为依据，重新决定真实建筑／自然环境的造型、构造、材料、生活或生态内容与呈现方式。

**不要把任务写成对白模模型贴图、换皮、上色或表面精修。** 白块大小轮廓、粗糙倒角、低面数、规则重复与空白背景都不是目标风格；真实设计可以改变非关键外轮廓、结构分层、环境丰富度和图片展示构图。改变不能封住必经通道、改变关键高差或斜度、迁移碰撞面和剧情遮挡。

每条包含白模帧的完整生图 prompt 都要写清三件事，不仅放在 JSON 外围字段里：

1. **输入只解释哪些逻辑。** 用本图实际关系列明 `preserve`，例如“倾斜玻璃主面与侧边检修槽相邻，突出箱体构成障碍，下方有悬吊平台”。
2. **真实场景如何重建设计。** 给出具体建筑或场地方案、真实轮廓与构件、材料和合理环境内容，落实 `design_freedom`，不只写“写实化”。
3. **不能直接贴图。** 明示不继承白模的低模外形、简化构件与空旷背景，不在原白块上覆盖纹理冒充成品；只在必要关系上保持一致。

推荐开头写法，必须把其中关系换成本图实际内容：

> 输入图片1仅作为空间逻辑示意：保留这里列出的通路、前后、高差和遮挡关系。基于这些关系重新设计一个完整可信的真实场景，重做真实物体轮廓、结构层次、构件连接、材料与环境内容。不要直接对白模贴材质或套照片纹理，不以白块外形和简化程度为最终设计。

这段是生图输入职责说明，不是数值参考权重。若输入另有已生成真实美术图，应分别说明它提供的外观，不把所有输入都称为白模。全景纯文生图不虚构“输入图片1”。

### 白模代理先说明语义与处理

在同一次规划中结合四素材与已抽取原帧，针对容易被生图模型误认的元素写清 **“可辨识特征／位置 → 实际语义 → 本张图如何处理”**，并放进实际发送的 prompt。同类代理可按所在区域、颜色或形状成组说明，不必逐人逐物点名。

- **识别以本次素材为依据。** 颜色、形状和位置只用于指认输入元素，不是固定语义词典；本片细柱可能表示人，另一片可能真是支柱。无法确认时只写有依据的关系，影响处理的未知沿用 `issues` 记录，不把猜测写成事实。
- **处理按本图用途决定。** 关乎剧情的墙、平台、道具等保留遮挡、承载、通行和接触逻辑，外观重新设计；人物需要入图时可重建为远景小比例真人。无人局部环境图才移除不应入图的人物代理，不由此全局删除人物或改变视频人数。
- **移除要写明恢复结果。** 去除的是代理占位及其轮廓，原处应恢复与周围相接的地面、墙面等合理场地；不能把被移除代理改成木桩、石块、碑柱或其他替代实物，也不能沿其队列补出一组设施。
- **构件依据真实功能布置。** 例如《错令》的真实木支护只沿既有壕壁承托，不按人物代理位置布置；确为墙体、支撑或道具的占位应按其语义重建，不能因为形似人物代理而一并删除。短例见 [image-prompt-examples.md](image-prompt-examples.md) 的 E 节。

这只是现有规划节点内的读帧与提示词说明，不新增模型调用、图像预处理、验图或自动重试；沿用 `preserve`、`design_freedom`、`prompt_constraints` 和完整 `prompt`，不增加字段。

## 官方依据与本项目适配

已检索并打开的 OpenAI 官方资料：

- [Image prompting](https://developers.openai.com/api/docs/guides/image-prompting)：明确成图用途、构图、可见材料与光线；给人物相对尺度和互动；逐张说明参考图用途，区分编辑内容与保留项。
- [GPT Image 1.5 提示指南：自然照片质感](https://developers.openai.com/cookbook/examples/multimodal/image-gen-1.5-prompting_guide#43-photorealistic-images-that-feel-natural)：用像真实现场拍摄的描述，写出自然纹理、光线和日常细节，避免过度修饰或摆拍感。此处借鉴写法，不据此指定用户的模型版本。

另参考真实环境资料，不作为 GPT 模型能力或参数说明：

- [Nikon 街拍指南](https://www.nikon.co.uk/en_GB/learn-and-explore/magazine/nikon-quickstart/improving-your-street-photography-with-your-nikon-quickstart-cheat-sheet)：人物与周围环境共同呈现自然城市日常；这里只借鉴生活感，不采纳人物近景方案。
- [Woodland Trust：阔叶林](https://www.woodlandtrust.org.uk/trees-woods-and-wildlife/habitats/broadleaved-woodland)：树冠、林下与地表植被有层次，植物组成受当地环境影响。树林提示词据此选择相容层次，不把某种林地的植物清单套到全部树林。

本文件的代理语义处理、城市与树林规则、背景群演边界和具体示例，是结合用户要求的编写方案，不是官方固定模板。官方示例中的“全部布局不变、禁止添加所有元素”不适用于本项目的美术重设计；只保留关键空间关系，允许补合理环境内容。官方讨论的迭代验图也不转为本 Skill 的自动步骤。

## 1. 先给环境设定，再选择内容

从四文件直接取得地点类型、年代、季节、天气、时段、开放或封闭状态，以及本图需要展示的区域。按这些信息选择日常设施、生活活动或自然层次，不另开审核流程。未明确到城市或树种时使用与现有情境相容的通用设计，不编造来源中没有的精确地理身份。

每条 prompt 用可见内容表达，可按需要分成“画面用途／空间关系／环境内容／真实细节与光线／限制”。写成完整自然语言；不依赖关键词权重、特殊括号或重复“8K、超真实”。图生图先说输入图只提供哪些关系，再说允许重新设计什么、补入什么。

**环境补充的表达单位是：对象＋所在区域＋分布或密度＋可见状态＋与主场景的关系。**

例如写“远处人行道上有疏散分布的小比例路人，服装符合当季，各自行走或在店面旁短暂停留”，比只写“有人气”更具体；写“路径两侧的树木疏密不齐，树下间断分布低矮灌木，落叶沿路缘聚集”，比只写“森林细节丰富”更具体。

## 2. 城市街道：补生活感

- **背景路人**：正常开放街道可按时段与地点加入合理人流，不能一律清空。人群只作远景小比例环境人物，分布、衣着和自然朝向有变化，可行走、等候或短暂停留，不排成整齐一列，不集体盯着镜头。明确空城、深夜封路、撤离或无人场景时遵守原设定。
- **日常设施**：按街道用途选择真实路缘、铺装接缝、排水口、树池、路灯、自行车停放点、店面橱窗或既有建筑的附属细节。不把设施清单全部堆进每张图，也不凭空增加改变路线的入口、桥梁或楼梯。
- **车辆与生活痕迹**：需要时在与行动路线分离的背景加入合理停靠车辆、远处正常车流、店铺开闭状态或适量日常物件。密度与城市类型、时段一致；不把背景车写成新追逐者，不增设交通事故或封堵。
- **场景联系**：玻璃反射相邻街景，人物和设施有接触阴影，路面状态与天气相容。生活感主要来自对象和活动关系，不靠满地垃圾、霓虹、浓雾或统一湿地面。

背景路人属于用户允许的环境补充，**不视作擅自新增剧情角色**。他们不接触关键道具、不攻击或救援主角、不成为新的目标或目击转折，不改变主动作的时间与结果。不要为他们新生人物参考图或安排人物中近景。

## 3. 树林：补自然层次

- **树木层次**：按既定林地类型设计树冠、树干粗细、枝干方向及疏密变化，形成前中后景；避免等距离重复同一棵树的布景感。关键树干、遮挡和通路仍按源空间关系保留。
- **林下与地表**：按季节和环境挑选低矮灌木、草本、落叶或松针、细小枯枝、树根边缘、小石块、裸土等，写明它们分布在哪里；不用每张图都有所有元素，也不把原有平整行动区改成起伏障碍。
- **生长与使用痕迹**：路径上可表现与已有通行相容的压实地面，路缘保留较自然的植物和落叶；潮湿环境可在适当阴湿位置加入少量苔藓等细节，干燥场景不强加大片湿苔。植被色彩、枯叶和地表湿度与同一季节、天气相容。
- **光与深度**：树冠遮光、林隙亮度和近远层次互相配合；按天气选择散射光或穿过林隙的日光。不得为“高级感”统一加浓雾、神光、发光植物或不相容的热带植被。

自然细节不自动扩大为新剧情：不默认增设动物、猎人、小屋、悬桥、溪流或分岔路线。除非源设定需要，不把小枯枝升级成横断行动通道的大倒木，不让新增灌木遮住关键动作或提前显露藏身处。

## 4. 丰富度与行动空间同时成立

明确保留主角路线、关键接触区、视线揭示和必要遮挡，再在其他合适位置补内容。丰富不等于堆满，也不等于只能加微小表面纹理。每张图选择最能说明地点的内容，形成有主次、有疏密的真实环境。

反向限制同样重要：不要为了“保证动作可读”把整条街或整个树林清空，只维持实际需要的局部行动空间。源素材已有的人群、车流或密林遮挡不能被当作可随意移除的干扰。

把环境补充写进完整 `prompt`，在 `space_source.design_freedom` 写允许添加的类型；`background_constraints` 写该区应有内容和边界。`video_usage` 说明哪些背景可在本镜可见区域继承。无需新增 JSON 字段或外部生产资料。

当参考图的路人、车辆或植被会进入最终视频时，在对应镜头写清背景延续：行人有低干扰的自然日常运动，植被可有与天气相容的轻微变化；不能定格成人形摆件、逐镜凭空刷新或突然穿过主角路线。这里只补充未建模的背景，白模仍控制摄影和剧情主体根运动。

## 5. 可直接参考的写法

下面是原创环境段示例，地点、时段和天气只在与本片相容时使用。将选用内容与本次用途、空间关系、参考输入和限制合并为一条完整 prompt，不原样套用所有细节。

### 城市街道

> 一张像真实现场拍摄的城市支路远景照片。沿街店面、路缘和人行道保持可信尺度，橱窗映出对面的建筑与树影。远处两侧人行道有疏散分布的小比例路人，衣着适合当季，各自行走或在店面旁短暂停留，彼此姿态与朝向不同。少量自行车停在背景靠墙处，路灯和树池沿街自然分布，铺装接缝与排水口有实际构造。侧上方日光使建筑、路人和设施的阴影方向一致，路面保持与天气相符的状态。画面有日常生活感，主行动区域仍按既定分镜保持可通行；背景人流不进入关键接触位置，不承担追逐、攻击或救援事件，不生成人物近景、文字标注或水印。

### 林间场景

> 一张像实地摄影的林间远景参考图。既定小径和关键树干位置关系保持可辨认，树木粗细与间距自然变化，近处树干、中景疏密不同的林下植物和远处相互遮叠的树冠形成层次。小径地面略有踩踏压实的痕迹，两侧零散分布低矮灌木，落叶、少量枯枝与小石块沿路缘自然聚集，树根边缘连接泥土，不像浮在地面上。叶色和落叶量与既定季节一致，林隙光与树冠阴影保留真实明暗，远处细节自然减弱。补充内容分布在不改变主角路线的位置，保留剧情需要的遮挡与视线，不新增岔路、横断路面的倒木、动物或建筑，不加文字标注、水印或拼图。

两段的目标都是让场景像一个实际存在的地方；无须额外生成背景人物资产，仍然按既有四文件规划、一次有效生成、直接绑定打包。
