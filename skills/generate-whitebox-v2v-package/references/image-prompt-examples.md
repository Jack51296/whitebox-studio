# 生图提示词示例

示例用于说明写法，地点、图数、配色和设施不能机械套到新片。每条图的空间和用途仍由本次四文件确定；生图 API 只看到本条 prompt 和实际传入图片。**优化目标是真实感与视觉细节**：结构与比例、材料差异、加工与使用痕迹、光照反射、接触阴影及自然摄影层次。按画面主次选择细节，新旧程度和天气服从本片设定，不把所有场景都做旧或淋湿。详细方法见 [action-and-detail-prompts.md](action-and-detail-prompts.md) 第4—5节。

生图使用用户的 GPT 接口。以下无人例子仅代表各自设计，不是所有环境必须无人的规则。街道路人、生活设施和树林层次的补充方法及示例见 [gpt-image-environment.md](gpt-image-environment.md)。

## A. 全景：纯文生图

任务：雨后高空追逐需要一张斜玻璃外立面的全局美术参考。生图请求不传图片，即使规划模型看过总览。

> 生成一张16:9真实电影实景质感的摩天楼外部全景美术参考图。雨后白天，一栋具有大面积倾斜玻璃外立面的现代高楼，完整交代屋顶出发区、向下延伸的斜面、凹入幕墙的检修轨道、突出墙面的通风箱和更低处的悬吊擦窗平台。外立面必须真正倾斜；轨道与主斜面相邻，凸出的通风箱保留撞击面，擦窗平台通过缆绳悬吊在较低位置，不以走廊或楼梯直接连接这些区域。
>
> 为建筑设计完整可信的结构与外观：倾斜幕墙由深灰钢构和规则金属龙骨支撑，大尺寸蓝灰玻璃单元沿坡面连续排列，接缝有窄压条和密封层，玻璃与屋顶交界有真实的包边收口；支撑结构不横穿人物滑落表面。凹入幕墙的检修轨道具有真实槽体和安装支座，通风箱为带折边的金属外壳，百叶与侧板有清楚层次，通过背部连接件固定在建筑上；下方平台具有钢制边框、金属底板和向上延伸的悬吊缆绳。构件的尺寸层级与整栋建筑相容，全景以楼体、坡面和设施之间的关系为主。
>
> 雨后较亮的阴天，云层散射光从画面侧上方照亮建筑；玻璃映出柔亮天空和偏暗城市轮廓，金属压条形成细窄高光，沿斜面下流的水痕与接缝附近的湿润区域带来局部反射差异，钢构保持克制的粗糙金属质感，不把整栋楼变成镜面。采用远距离斜侧宽全景，同时读清坡面深度、屋顶出发区和下方平台的高差；远处城市略有空气透视，建筑轮廓清楚，现代动作电影的蓝灰与中性灰色调。
>
> 画面无人。不要白色低模方块或只贴纹理的模型外观，不把斜墙改成垂直墙，不新增跨越危险区的桥梁、救援设施、人物、武器、文字、尺寸标注、水印或分屏。这是场景美术设计，视频仍按各自原分镜取景，不复制本图全景机位。

重点：主动给出真实建筑方案；没有“输入图片1”；不要求源视频有同样的全景。

## B. 局部：只借关键关系的图生图

任务：窄巷侧缝连到放箱托盘的转折区域。输入图片1为该区域的白模原帧；没有额外外观依赖图。

> 输入图片1只提供空间逻辑，不提供最终外观：保留两排集装箱形成可通行窄巷、近侧箱排留有成年人可侧身穿过的真实缝隙、缝隙另一侧紧邻低矮托盘这三个关系。基于这些关系重新设计一张16:9真实电影场景美术图，重做真实箱体轮廓、构造连接与环境细节；不要直接在白模原几何上贴材质、套照片纹理或只换颜色，不继承白块的简化造型与空旷程度。箱子和人物的动作时刻在视频中另行控制。
>
> 把白模体块重新设计成可辨认的真实货运集装箱：厚实上下边梁和角柱组成受力框架，角件嵌在框架端部，侧面瓦楞钢板有连续起伏、板缝和焊接收口。使用低饱和灰绿与石墨灰漆面，迎光面略微褪色，搬运易碰的边角露出冷灰金属，少量锈痕集中在接缝和下边梁；完整大面保持连续漆层，不均匀涂满污渍。缝隙边缘是两组真实箱体框架，侧身通行空间完整，不能增加横跨缝隙的斜撑。
>
> 低矮托盘由有实际厚度的木板、纵向承托和垫块组成，板条间留缝，承重面平整，边角有轻微磨损与木纤维痕迹，放在缝外既定位置。地面是有伸缩缝的旧混凝土，箱底与托盘下方有接触阴影，少量尘土沿边缘积聚。正午日光从箱排侧上方照入，瓦楞板明暗交替，窄巷内部较暗，出口一侧较亮但保留材质层次；阴影方向一致，通过亮度层次把巷内、缝隙和缝外空地的连接读清。
>
> 采用能同时交代巷、缝和托盘的高位斜看场景构图，可以调整展示角度、画面占比及非关键外轮廓，不需要逐像素复制输入图。本例示意棋子代表人物而非设施；场景无人，移除这些棋子及其轮廓，原处恢复连续可通行的混凝土地面，不用立柱、箱子或其他实物替代；不要只给原方块换颜色贴材质。不得把缝封成实体墙、把托盘搬进巷中或增加第二条捷径；不迁入画外终点、大型吊车、海面或城市地标，不加人物、武器、文字、水印和拼图。

重点：明确保留少量关系，并明确哪些设计可以重做。此图不作为视频的新机位；视频仍按原分镜摄影。

## C. 同场景外观依赖

若B确实需要传入已生成的全景图作为输入图片2，应在B正文增加具体范围，并同步填写 appearance_sources 与 reference_image_ids：

> 输入图片2只提供集装箱的灰绿与石墨灰配色、钢板磨损和日光色调；不提供整体布局、相机角度、远处出口或任何人物和道具状态。当前区域的巷、缝、托盘关系仍来自输入图片1。

不要写“完全保持图2的一切”。无需依赖时，让两个图片任务用相同文字美术设定独立生成，不强行增加依赖。

## D. 非人物资产：纯文生图

> 生成一张真实电影道具参考照片：单只沉重的深石墨色硬壳手提箱，放在干净中性灰背景上。横长箱体有实体厚度和圆钝转角，箱盖与箱身之间有连续接缝和嵌入的密封边，浅银金属加强箍沿箱体包覆；顶部提手通过两处可靠支座固定，提手下方留有可四指握入的空间，握持段略有磨亮。壳体大面为粗糙细纹表面，边角有少量浅划痕，金属箍反光比外壳集中但不呈镜面。箱盖闭合，接缝对齐。
>
> 自然三分之四展示角度，清楚看见整体厚度、顶部提手和加强箍；大面积柔光从侧上方照入，另一侧较暗，箱底有清楚接触影，材质层次来自真实反光差异。没有人物、手、托盘或剧情场景；不增加轮子、武器、商标、文字、尺寸线、水印或拼图。该图只定义道具外观，视频中的持有者、左右手、位置和运动按既有分镜变化，不继承中性背景和展示机位。

只在确有独立道具设计需求时加此图，不每片固定生成资产图。

## E. 先说明代理语义，再移除不入图的人物

仅当本次四素材确认这些形态表示人物时使用，如《错令》的无人壕口局部图；不是“蓝柱或黄柱永远代表人”的通用规则。以下短段嵌入完整场景 prompt：

> 输入帧中通行带上的蓝色单柱是传令兵占位，前沿开阔地成排的黄色竖柱是占领士兵占位，不是木桩、石柱或防御设施。本张图只设计无人环境，移除这些人物代理及其轮廓，原处恢复与周围连续相接的压实土面，不以柱桩、石块或其他实物替代，不沿原人物队列新建构件。实体折角墙继续承担遮挡，绕角通行带和队列活动空地保持原有功能；真实木支护只沿既有壕壁设置。人物在最终视频中仍按原人数和路线恢复。

若本图需要远景人物，应把对应代理重建为小比例真人，而非套用此例全部移除；真实墙、平台和道具也应按各自语义保留功能并重设计外观。
