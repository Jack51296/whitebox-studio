# 故事驱动 / 长镜头白模

来源：[D5] 白膜制作流程（需求 → 范围 → 故事 → 分镜与联合调度 → 白模 → 试拍 → 看片 → 交付包）；
[D7] 长镜头规划模式（Scene Zones → 俯视空间图 → 唯一连续相机路径 → 灰盒预演）；
交付格式沿用团队 whitebox-world-studio 1.2.0 交付包（导演卡、续作提示词、故事板、路线图、报告）。

## 步骤

1. `wbs doctor` 确认工具。
2. 故事短片：
   ```
   wbs forward story --batch S20260927 --job S001 --brief "两人抢一只滚动的箱子，最后一起抬走" --content-class motion
   ```
   - 规划模型默认是 mock（离线可跑，结果标注“模拟规划”）。接真实模型：在 `configs/providers.yaml` 选 openai_compatible，
     在环境变量里配置网关地址和密钥（本仓库不保存、不打印密钥），先 `--dry-run` 看预估，再加 `--confirm-paid`。
   - 规划结果先过 StoryPlan 契约（字段、类型、路径覆盖全部人物），镜头边界自动吸附到帧；再过渲染前动态闸门。
3. 长镜头：
   ```
   wbs forward longtake --batch L20260927 --job L001 --brief "从门厅一路走到屋顶平台" --zones 6
   ```
   - 区域按顺序相通（直行或 90° 转向，不与已有区域重叠），墙体合并去重并在路线处开门洞；相机一镜到底，主体在前方 3 米穿行。
4. 看结果：导演卡的“逐镜/镜内阶段”、续作提示词 A/B 两段、`路线俯视图.png`（只用于核对，不进成片）。
5. 需要真人化时交给 generate-whitebox-v2v-package：`wbs v2v run <任务目录>`。

## 创作规则

- 故事要有人物目标、主动选择、转折和后果；转折依据必须在前面镜头里交代，不靠临时出现的接应者或道具。
- 空间先行：米制坐标，+Y 为北，地面 z=0；先设计场地、入口、出口、通道和遮挡，再排人物路线，路线不穿体块。
- 最小建模：人物是无四肢代理，只平移和绕竖轴转向；武器、魔法、手持物只写在文字里（semantic_only），不建可见几何。
- 镜头首尾相接、覆盖全片；每镜写清摄影任务和动作；一镜到底只有一个镜头。
- 不使用任何第三方影视片段或针对具体影片的提示词；世界观由需求给出。
- 人工复核只由看过的人标记（`wbs review mark`），程序不代填观感通过。
